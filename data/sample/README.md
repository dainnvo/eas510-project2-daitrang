# Bundled real-data excerpt sample

This directory contains **80 real, modified ESConv greeting excerpts**, not synthetic conversations and not a representative training corpus. Each record contains one neutral seeker opening and the original next supporter strategy label. The supporter content is deliberately empty; the input builder uses only preceding messages, so that content is unnecessary. No later responses, situation descriptions, surveys, or personal disclosures are bundled.

Selection is reproducible with `python data/make_sample.py` after full-data acquisition. It uses exact reviewed greetings, takes candidates only from the full-data training partition, shuffles with seed 510, and selects 80 conversations without optimizing for labels or results. [selection.json](selection.json) records the allowlist, eligible count, counts by label, and modifications. The sample gets its own 56/12/12 conversation split for the offline demonstration. Repeated greetings are expected. Some strategies are absent; macro F1 still uses the fixed eight-label list with zero for undefined classes.
